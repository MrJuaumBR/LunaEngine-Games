# LunaEngine-Games

## What is it?
It is a game repository for [LunaEngine](https://mrjuaumbr.github.io/LunaEngine).
> [Games](./games/) folder;
> [Zip Games](./games-build/) folder.

## How do I add my game?
It's simple: just go to our [Discord](https://discord.gg/fb84sHDX7R) and speak with one of the staff members. The game will be reviewed and, shortly after approval, it will be added to [ext.json](ext.json) as a repository URL.

But for it to be approved, it needs to have an `info.yaml` following the [guide](./information_guide.md) rules and a `requirements.txt` with all the requirements the game has.
Also, it doesn't necessarily need to be a game made with *LunaEngine*; it can use other frameworks as well.
